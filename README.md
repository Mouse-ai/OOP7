# OOP7 — Дерево объектов и Observer

Лабораторная работа 7 развивает визуальный редактор из ЛР6.

## Реализовано

- отображение объектов и вложенных групп в TreeView;
- двусторонняя синхронизация выделения между рабочей областью и TreeView;
- Observer между `ShapeStorage` и `ShapeTreeWidget`;
- однонаправленные стрелки между объектами и группами;
- перемещение объекта-цели при перемещении объекта-источника;
- транзитивные связи и защита от бесконечной рекурсии в циклах;
- корректная работа стрелок при группировке и разгруппировке;
- сохранение и загрузка стрелок вместе с проектом;
- отмена действий через Ctrl+Z.

## Пользовательские истории

### 1. Стрелка между двумя группами и разгруппировка

1. Создать объекты A и B и объединить их в группу G1.
2. Создать объекты C и D и объединить их в группу G2.
3. Создать стрелку G1 → G2.
4. Переместить G1 и убедиться, что G2 перемещается вместе с ней.
5. Разгруппировать G1.
6. Убедиться, что приложение продолжает корректно работать и не обращается к удалённой группе.

### 2. Группировка объекта, уже соединённого стрелкой

1. Создать объекты A, B и C.
2. Создать стрелку A → B.
3. Объединить B и C в группу G.
4. Переместить A.
5. Убедиться, что перемещается вся группа G, а не только B.
6. Разгруппировать G и убедиться, что связь A → B продолжает работать.

### 3. Транзитивная цепочка стрелок

1. Создать объекты A, B, C и D.
2. Создать стрелки A → B, B → C и C → D.
3. Переместить A.
4. Убедиться, что B, C и D также переместились на то же смещение.
5. Переместить C отдельно и убедиться, что перемещается D, но A и B не перемещаются.

### 4. Замкнутый ориентированный цикл

1. Создать объекты A, B и C.
2. Создать стрелки A → B, B → C и C → A.
3. Переместить A.
4. Убедиться, что A, B и C переместились ровно один раз.
5. Убедиться, что приложение не зависает и не возникает бесконечная рекурсия.

### 5. Сохранение и восстановление сложной структуры

1. Создать несколько объектов и вложенную группу G1, содержащую другую группу G2.
2. Создать несколько стрелок между отдельными объектами и группами, включая транзитивную цепочку.
3. Сохранить проект в текстовый файл.
4. Удалить объекты из рабочей области.
5. Загрузить сохранённый проект.
6. Убедиться, что восстановились фигуры, вложенные группы, TreeView и все стрелки.
7. Переместить объект-источник и убедиться, что восстановленные связи продолжают работать.

## Управление

- `1` — круг;
- `2` — прямоугольник;
- `3` — квадрат;
- `4` — треугольник;
- `5` — эллипс;
- `6` — отрезок;
- стрелки клавиатуры — перемещение;
- `+` / `-` — изменение размера;
- `C` — изменение цвета;
- `Delete` — удаление;
- `Ctrl+G` — группировка;
- `Ctrl+Shift+G` — разгруппировка;
- `Ctrl+Z` — отмена последнего действия;
- `Ctrl+S` — сохранение;
- `Ctrl+O` — загрузка.
